# 🐶🐱 Dog vs Cat Image Classifier

A high-accuracy deep learning model built using **TensorFlow** to classify images as **Dog** or **Cat**. Achieves **over 95% accuracy** on a dataset of 1k+ images using a custom **Convolutional Neural Network (CNN)**.

---

## 🚀 Live Demo

🎯 Try it out on [Hugging Face Spaces](https://huggingface.co/spaces/Sarthaknarula/DogvsCatClassifier)

---

## 🧠 Model Highlights

- ✅ **Accuracy**: 95%+
- 🧠 **Model**: Custom Convolutional Neural Network (CNN)
- 🖼️ **Input Size**: 256x256 RGB images
- 🧪 **Framework**: TensorFlow / Keras
- 📊 **Dataset**: 1k+ labeled images of dogs and cats
- ⚡ **Deployed with**: Gradio on Hugging Face Spaces
